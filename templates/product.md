# Product

> Template for `.brainstorm/dimensions/product.md`
> Explorer uses these sections as conversation anchors during exploration.

## Problem Statement

What pain point does this solve, who feels it most acutely, and how severe is it? Include the trigger — what situation makes someone look for a solution.

## Proposed Solution

Core concept and how it addresses the problem. Focus on the approach, not a feature list. What is the insight that makes this solution work?

## Key Features

Prioritized list of features. Separate MVP (must-have for first version) from future (nice-to-have, post-launch). For each feature, note which problem it addresses.

## Differentiators

What makes this unique compared to existing alternatives. Be specific — "better UX" is not a differentiator. What can you do that others cannot or will not?

## User Experience Vision

How it should feel to use this product. What is the emotional response? What does the ideal workflow look like from the user's perspective?

## Assumptions & Risks

What must be true for this product to work? List the key assumptions and for each one, note what happens if it is wrong. Include technical, market, and user behavior risks.
