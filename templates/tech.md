# Tech

> Template for `.brainstorm/dimensions/tech.md`
> Explorer uses these sections as conversation anchors during exploration.

## Architecture Overview

High-level system design. Major components, how they interact, data flow. Keep it at the level where someone can understand the system in 2 minutes.

## Tech Stack Choices

Languages, frameworks, infrastructure — with rationale for each choice. Note what alternatives were considered and why they were rejected.

## Build vs Buy Decisions

What to build from scratch, what to use off-the-shelf (libraries, services, APIs). For each decision, note the tradeoff: control vs speed, cost vs flexibility.

## Technical Constraints

Performance requirements, scalability targets, security requirements, compliance needs. What are the non-negotiable technical boundaries?

## Development Approach

MVP build strategy — what to build first, what to defer. Iteration plan and how technical debt will be managed. Team size and skill assumptions.

## Technical Risks

Unknowns, complexity hotspots, integration risks, scaling concerns. For each risk, note likelihood, impact, and mitigation approach.
