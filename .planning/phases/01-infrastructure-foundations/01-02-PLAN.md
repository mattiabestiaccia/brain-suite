  <name>Task 1: Create install.sh with symlinks, collision detection, and manifest</name>
  <files>install.sh</files>
  <action>
    Create `install.sh` at repo root. Must be executable (`chmod +x`).

    **Script structure (per CONTEXT.md locked decisions and RESEARCH.md patterns):**

    1. **Shebang and strict mode:** `#!/usr/bin/env bash` with `set -euo pipefail`.

    2. **REPO_DIR resolution:** Use cross-platform pattern: `REPO_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"` (works on bash 3.2+ macOS and bash 5+ Linux).

    3. **Color output:** Define GREEN, YELLOW, RED, NC (no-color) ANSI codes. Detect if terminal supports color with `tput` fallback to no-color.

    4. **Counters:** `linked=0`, `warned=0`, `failed=0`.

    5. **Pre-checks:**
       - Verify `~/.claude/` exists. If not, create it with `mkdir -p "$HOME/.claude"`.
       - Verify required source files exist in repo: `commands/brain/`, `agents/brain-explorer.md`, `references/voice-interaction.md`. If any missing, print error and exit 1 immediately ("Missing source files. Is this the brain-suite repo?").

    6. **Manifest initialization:** `MANIFEST="$HOME/.claude/.brain-suite-manifest"`. Truncate: `> "$MANIFEST"`.

    7. **Symlink: commands/brain/ directory.**
       - Target: `$HOME/.claude/commands/brain`
       - Use `ln -sfn` (NOT `ln -sf` — see RESEARCH.md Pitfall 1 for directory symlinks).
       - Log: "✓ linked: commands/brain/" or "✓ updated: commands/brain/" if already existed.
       - Append path to manifest.
       - Increment linked counter.

    8. **Symlink: individual agent files.**
       - For each `agents/brain-*.md` file in REPO_DIR:
         - Target: `$HOME/.claude/agents/$(basename "$f")`
         - **Collision detection** (per RESEARCH.md Pattern 2):
           - If target is a symlink AND `readlink "$target"` starts with `$REPO_DIR` → our symlink, safe to update with `ln -sf`. Log "updated".
           - Else if target exists (file or broken symlink) → NOT ours. Log "WARN: ... already exists (not Brain Suite) — skipping". Increment warned. Skip.
           - Else → fresh install. `ln -sf`. Log "linked".
         - Append path to manifest for each successful link.

    9. **Symlink: references/ directory.**
       - Create real directory: `mkdir -p "$HOME/.claude/brain-suite"`.
       - Symlink: `ln -sfn "$REPO_DIR/references" "$HOME/.claude/brain-suite/references"`.
       - Append `$HOME/.claude/brain-suite/references` to manifest.
       - Also append `$HOME/.claude/brain-suite` to manifest (real dir, for cleanup tracking).

    10. **Summary output:**
        ```
        Brain Suite installation complete.
          {linked} files linked  {warned} skipped  {failed} errors

        Restart Claude Code for commands to appear.
        ```

    **Important implementation notes:**
    - All manifest paths must be absolute (expand `$HOME` at write time, per RESEARCH.md Pitfall 5).
    - Templates are NOT symlinked per CONTEXT.md ("Templates are NOT symlinked — agents read them directly from repo path").
    - The manifest is a plain-text file, one absolute path per line — no JSON.
    - Do NOT use `set -e` for the entire script — use explicit error handling per RESEARCH.md anti-patterns. Instead, use `set -euo pipefail` at top but wrap individual `ln` calls in functions that handle errors gracefully.
  </action>

    Run: `./install.sh` again — idempotent, same result, no errors.

<task type="auto">
  <name>Task 2: Create uninstall.sh with manifest-based safe removal</name>
  <files>uninstall.sh</files>
  <action>
    Create `uninstall.sh` at repo root. Must be executable (`chmod +x`).

    **Script structure (per CONTEXT.md locked decisions):**

    1. **Shebang:** `#!/usr/bin/env bash` with `set -euo pipefail`.

    2. **REPO_DIR resolution:** Same pattern as install.sh.

    3. **Color output:** Same as install.sh.

    4. **Counters:** `removed=0`, `skipped=0`.

    5. **Manifest check:**
       - `MANIFEST="$HOME/.claude/.brain-suite-manifest"`
       - If manifest doesn't exist: print "No Brain Suite installation found (manifest missing)." and exit 0 (not an error).

    6. **Read manifest and remove:**
       - `while IFS= read -r path; do` from manifest.
       - Skip empty lines.
       - For symlinks (`[ -L "$path" ]`): `rm "$path"`, log "✓ removed: $path", increment removed.
       - For real directories (`[ -d "$path" ]`): check if empty. If empty, `rmdir "$path"`, log "✓ removed directory: $path". If not empty, log "- kept (not empty): $path", increment skipped. This handles `~/.claude/brain-suite/` — after removing the references symlink inside it, the directory should be empty and removable.
       - For anything else: log "- skipped (not found): $path", increment skipped.

    7. **Remove manifest itself:** `rm "$MANIFEST"`, log "✓ removed manifest".

    8. **Clean up empty parent dirs:**
       - Check if `$HOME/.claude/commands/brain` directory was removed. If so, check if `$HOME/.claude/commands/` is now empty. If empty, remove it. (But typically it won't be empty because GSD commands exist.)
       - Per CONTEXT.md: "Removes commands/brain/ directory if empty after symlink removal; preserves if user added custom files." Since brain/ is our symlink (not a real dir), removing the symlink removes the namespace. No further check needed.

    9. **Summary output:**
       ```
       Brain Suite uninstalled.
         {removed} removed  {skipped} skipped
       ```

    **Important implementation notes:**
    - No confirmation prompt per CONTEXT.md ("No confirmation prompt — direct removal with summary").
    - Per CONTEXT.md: "Never touches GSD files, other agents, or anything not in manifest."
    - Only remove what's in the manifest. Nothing else.
  </action>
  <verify>
    Run: `bash -n uninstall.sh` — syntax check passes.
    Run: `./install.sh` first (to create symlinks), then `./uninstall.sh`.
    Run: `test -L "$HOME/.claude/commands/brain" && echo "FAIL" || echo "PASS"` — symlink removed.
    Run: `test -L "$HOME/.claude/agents/brain-explorer.md" && echo "FAIL" || echo "PASS"` — symlink removed.
    Run: `test -f "$HOME/.claude/.brain-suite-manifest" && echo "FAIL" || echo "PASS"` — manifest removed.
    Run: GSD agents still exist: `test -f "$HOME/.claude/agents/gsd-executor.md" && echo "PASS" || echo "N/A (no GSD)"`.
    Run: `./uninstall.sh` again — graceful "No installation found" message.
  </verify>
  <done>
    uninstall.sh reads manifest, removes exactly those symlinks and empty dirs, removes the manifest itself, leaves GSD and other files untouched, and handles missing-manifest gracefully.
  </done>
